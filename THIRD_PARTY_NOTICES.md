# Research and third-party notices

No third-party DLL, game executable, game asset, MinHook, SDL, DXVK, ReShade,
or other binary is included in this project.

The implementation is original to this project. These open-source projects
were studied as behavioral and reverse-engineering references:

- DeadSpace2008Fixes by seamusduncmcgrath (MIT): feature comparison, known
  signatures, and public issue reports.
  https://github.com/seamusduncmcgrath/DeadSpace2008Fixes
- DSOpt by Luminous/Kanadeforever (MIT): research showing that correct subtitle
  scaling must cover both preprocessing/layout and final drawing.
  https://github.com/Kanadeforever/DSOpt
- MarkerPatch by Wemino/realdody (MIT): high-FPS Havok and VSync research for
  Dead Space 2. Its game-specific patches are not used here.
  https://github.com/Wemino/MarkerPatch

Microsoft Direct3D, XInput, and Windows API names are used only to interoperate
with the user's own Windows and game installation.
